# tabs-underline

Custom **tabs** block. Purpose: Accessible tablist (arrow/Home/End keys) with an orange underline on the active tab over a grey rule.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: [tab label | panel content (paragraphs, lists)]. Bare text in a panel cell is wrapped in a paragraph.

## Behaviour

- Click or Arrow/Home/End keys switch tabs; first tab is selected by default.
- When the tabs overflow (mobile), prev/next chevron buttons with a white fade scroll the tab bar, as on the source.

## Supported variations

No variations.
